# Examples

Two complete runs, each with the model input, the report source (`report.json`), the PDF and the Excel workbook.

- **copostly/** — a done-for-you LinkedIn agency assessed from public data only (the founder gave no numbers). Verdict: *not assessable yet* — the report says what the founder has to measure. Russian.
- **dentiqueue/** — a dental-clinic SaaS with six paying customers, run "cold" by a fresh Claude session from a founder brief (screening, case card and evidence pack included). Verdict: *proceed with conditions*. Russian.

Rebuild either with the commands in `SKILL.md` § Step 5 (the charts and manifests are regenerated by the pipeline).
